🛡️ О проекте

Что это?

D&D Online — бесплатная браузерная платформа для игры в Dungeons & Dragons 5e с ИИ Мастером Подземелий. Не нужно ничего скачивать, устанавливать или покупать — только браузер.

Как работает?

  • ИИ Ведущий — использует Groq или Google Gemini (бесплатные API) для ведения кампании
  • Карта — HTML5 Canvas с сеткой, токенами, туманом войны
  • Сеть — MQTT протокол через бесплатный брокер (без регистрации)
  • Кубики — встроенный генератор случайных чисел

Технологии

MQTT Реальное время
Canvas Карта и токены
Groq / Gemini ИИ Ведущий
Vanilla JS Без фреймворков

Развертывание

Сайт можно разместить бесплатно:

  • GitHub Pages — github.com → Settings → Pages
  • Netlify — перетащите папку на netlify.com
  • Vercel — импорт папки на vercel.com

Ограничения

  • До 4 игроков одновременно
  • ИИ Ведущий требует бесплатный API ключ
  • Хост должен быть онлайн для мультиплеера
  • MQTT брокер может иметь задержку ~100-200мс

Лицензия
